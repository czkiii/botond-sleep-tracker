# Solemi Sleep demo import

`solemi-demo-v4-2026-08-26.json` is a clean, reusable V4 backup for internal testing.

- Boti: 30 days with a deliberate older-to-newer wake-window trend and two naps per day.
- Frici: 8 days of denser newborn sleep periods.
- No profile photos, Family Sync identifiers, active sessions, overlaps, or intentionally corrupt records.
- All names and sleep records are synthetic test data.

Import it from Settings → Import data. The app downloads the current data as a backup before replacing it.
